摘要
工业生产现场正在从人工巡检、定期维护向智能运维、在线感知和无人化辅助作业演进，但传统指针式仪表、数字面板和控制柜窗口仍大量存在。粉尘、油污、水汽和反光会降低仪表可见性，进而影响人工读数和机器视觉识别的可靠性。仪表表面维护不仅是清洁动作，更是工业视觉巡检链路中的前端保障环节。
本项目以“慧眼除垢，化繁为简”为总体思路，受到人形机器人舞台化展示和工业具身智能发展的启发，将研究对象聚焦到工业仪表擦拭这一具体任务。我们具体实现的任务如下：
其一，团队完成了本地示教、AutoDL 云端训练和本地部署验证的工程闭环；其二，围绕标准擦拭、位置偏移、尺寸变化、污渍判断、海绵抓取偏差、光照扰动、真实厂房采集和失败样本补录等场景整理了201个episode；其三，采用ACT动作分块策略学习从全局图像、腕部图像、关节状态和夹爪状态到连续动作块的映射，使机械臂完成海绵抓取、仪表定位、污渍判断、擦拭执行和复位。
实验与统计分析表明，多视角输入、关节状态融合和失败样本微调能够改善仪表位置变化、污渍状态差异和海绵抓取偏差下的任务表现。报告围绕数据集构成、训练损失收敛、模型消融、污渍判断、末端定位偏差、阶段耗时和失败类型等结果展开分析，并进一步讨论系统在固定点位巡检、仪表读数前端维护和非结构化清洁任务中的应用价值。

第一章  绪论
工业现场的智能化升级并不只体现在新增高端设备和复杂控制系统上，也体现在对既有设备、传统仪表和基础维护流程的再组织、再感知和再自动化。当前，许多工厂正在建设数字化巡检、机器视觉读数和智能运维平台，但传统指针式仪表、数字显示面板和控制柜窗口仍广泛存在于实际生产系统中。这些设备往往安装周期长、数量多、分布分散，是工业现场运行状态的直接信息入口。对于此类仪表而言，表面可见性直接影响人工读数、相机采集和后续状态判断的可靠性。
在实际运维过程中，仪表表面污染是一类容易被忽视但频繁出现的问题。粉尘、油污、水汽、反光和人工接触痕迹会降低仪表读数清晰度，使巡检人员需要先擦拭再读取，也会使机器视觉系统面临图像模糊、局部遮挡和识别置信度下降等问题。与大型维修、复杂装配或高风险作业相比，仪表擦拭任务的单次操作并不复杂，但它具有重复性强、点位数量多、环境差异明显、工具接触状态不稳定等特点。正因如此，该任务适合作为具身智能技术进入工业维护场景的一个具体切入点：任务边界清晰，实验条件可控，同时具有真实的工业应用背景。
本项目的灵感来源于近年人形机器人舞台化展示与工业具身智能的发展。2026 年中央广播电视总台春节联欢晚会中，人形机器人在武术、舞蹈和人机协同表演中体现出较好的动作同步性和运动控制能力，其背后反映的是示教数据、动作组织、感知反馈和控制执行之间的系统协同。该现象启发我们思考：如果较复杂的舞台动作能够通过数据、模型和控制系统被机器人较稳定地复现，那么工业现场中大量重复、低风险但频繁发生的维护动作，也可以尝试通过示教数据和端到端策略学习来完成。与舞台展示相比，工业维护动作更强调稳定性、可复现性和场景约束，因此也更适合作为具身智能从演示走向应用的过渡型任务。
基于上述认识，本项目将研究对象聚焦为工业仪表擦拭任务，提出“慧眼除垢，化繁为简”的总体思路。其中，“慧眼”强调双相机视觉感知和污渍状态判断，“除垢”对应仪表表面维护任务，“化繁为简”则体现项目试图减少传统轨迹规划、显式建模和复杂条件规则的依赖，通过示教数据和 ACT 动作分块模型学习从视觉观测到机械臂动作序列的映射关系。项目并不追求覆盖所有工业清洁场景，而是在固定或半固定巡检点位中验证机械臂完成仪表表面维护的可行性。

图3-8上半部分展示了系统在线推理时的主数据流。全局相机输入Ig用于提供仪表、机械臂和工作空间的整体位置关系，腕部相机输入Iw用于补充海绵与仪表表面的局部接触信息，关节状态qt和夹爪状态gt则提供机械臂当前姿态和末端执行器状态。两路图像分别经过视觉编码器提取视觉token，关节与夹爪状态经过MLP状态编码器得到状态嵌入，随后在模态融合模块中进行token融合和位置编码，形成统一的状态表示。
在策略输出阶段，ACT policy network 不直接输出单步动作，而是通过 Action Chunking Transformer 预测未来一段连续动作块at:t+k-1。该动作块经过滚动时域执行机制下发到本地机械臂控制端，使系统能够连续完成海绵抓取、接近仪表、擦拭表面和撤离复位等动作。与单步动作回归相比，动作分块方式更适合擦拭这类具有连续阶段和长程依赖的任务，有助于降低逐步执行中的误差积累。

6.1 当前存在的问题
当前系统仍处于原型验证阶段，主要问题包括真实场景覆盖范围仍有限、接触力反馈不足、强反光条件下视觉稳定性需提升、长程任务状态切换仍可能受到前序误差影响等。图6-1根据团队复盘记录绘制鱼骨图，目的是把问题来源按照数据、感知、控制、接触和安全等方向进行归纳。

综合来看，后续工作可从三个方面展开。第一，继续扩充真实厂房、复杂光照、不同仪表类型和多种污染状态下的数据，使模型具备更充分的工况覆盖能力。第二，在现有视觉输入和关节状态基础上，引入力觉传感器或关节电流反馈，使系统能够感知擦拭接触状态，降低柔性工具接触不稳定带来的影响。第三，建立分层控制和异常检测机制，将“寻找工具—抓取—接近仪表—擦拭—复位”等阶段显式纳入任务监控过程，提升长程任务执行的安全性和稳定性。
6.3 项目总结
总体来看，本项目初步验证了基于示教数据和端到端动作学习的机械臂系统在工业仪表维护任务中的可行性，为具身智能技术进入工业基础运维场景提供了一个可展示、可迭代的实践样例。后续仍需围绕真实场景数据扩充、力觉反馈引入、分层控制、异常检测和固定工位长期测试继续完善，使系统从原型验证逐步走向更稳定的工程应用。
